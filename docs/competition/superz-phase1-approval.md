## D1 — voice: option (a), disclosed preset voice

Proceed with the preset voice `jam`, **pinned for every cue in the batch**. Do not vary
the voice between cues; one consistent narrator for the whole entry.

Voice cloning is dropped from this delivery entirely. **Do not request, record, or
transmit any reference voice sample.** The original handoff assumed a cloning engine;
that assumption was mine and it is withdrawn.

The disclosure this requires, stated verbatim in the entry:

> Narration is a synthetic preset voice (`jam`), generated by text-to-speech. No human
> recording and no voice cloning is used in this entry.

This sentence is a delivery requirement, not a courtesy: a synthesised voice presented
as a human recording would fail the entry's own accuracy rules.

## D2 — format: native 24 kHz, do not resample

**Deliver the native output untouched** — 24 kHz mono `pcm_s16le`, exactly as measured.
Do not resample to 48 kHz, do not normalise, do not trim.

The reasoning, so the choice is not mistaken for laziness: a 24→48 kHz resample adds no
spectral content, and performing it at the source would put an undocumented transform
between the synthesis and the file that is supposed to prove it was unprocessed. The
one unavoidable conversion belongs in the mux step, on my side, where it is logged.
`postProcessing: "none"` therefore stands unchanged, and the acceptance check becomes
"native rate, truthfully recorded in the manifest" rather than "48 kHz".

`captionText` must match the cue list byte-for-byte. `speechText` is `captionText` with
the pronunciation respellings applied and **nothing else changed** — that is checked as
a diff, so any other edit fails the delivery.

`leadingSilenceMs` is measured, not estimated. It is compensated in placement, so a
file with 180 ms of leading silence is fine and must not be trimmed to hide it.

## Fitting a cue to its window (replaces the bare duration rule)

You have no per-cue duration control, so use this ladder in order and report which step
was used in `speed`:

1. **Default:** `speed: 1.0`, deliver as synthesised.
2. **If `durationMs` exceeds `windowMs`:** re-synthesise that cue at up to `speed: 1.15`.
   Report the value actually used. Above 1.15 the prosody audibly degrades.
3. **Still over:** deliver it anyway, flagged. Do **not** shorten the text yourself —
   the text states a claim that has been reviewed, and changing it requires re-approval.
